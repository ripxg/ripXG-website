The best AI agents aren't static—they learn, adapt, and improve over time.

That's the philosophy behind **[Better Claw](https://better-claw.vercel.app/)**, a curated library of OpenClaw cron jobs that implement continuous self-improvement loops.

## The Problem with Static Agents

Most AI agents start strong but stagnate. They don't learn from their mistakes. They don't adapt to your communication style. They don't monitor project health or maintain their own memory.

They're reactive, not proactive.

Better Claw changes that.

## What Is Better Claw?

Better Claw is a collection of scheduled tasks (cron jobs) that help your OpenClaw agent:

- **Learn from patterns** — Daily reflection on what works and what doesn't
- **Stay accountable** — Regular check-ins on projects, usage, and progress
- **Maintain health** — Catch stale memories, detect stalled work, monitor security
- **Discover capabilities** — Gradually explore and adopt new tools
- **Respect your time** — Brief, actionable reports that inform without overwhelming

Think of it as a personal trainer for your AI agent.

## Job Categories

Better Claw organizes jobs into categories:

### 🔄 Feedback & Learning
- **Daily workflow feedback**: Reflects on communication patterns and process improvements
- **Weekly reflection**: Summarizes accomplishments, lessons learned, and goals
- **Learning preference calibration**: Monthly check-in on how the agent should adapt to your style

### 📊 Usage & Analytics
- **Token usage daily**: Track costs and resource usage
- **Session summary**: Weekly activity reports (spawns, models used, costs)
- **Tool usage report**: Identify which tools are used most/least

### 🏗️ Project Health
- **Project owner**: Monitor deployments, PRs, and issues for each repo
- **Stalled work detector**: Catch projects with no commits in 7+ days
- **Dependency update check**: Track outdated dependencies and security updates

### 🧠 Memory & Context
- **Memory health check**: Detect stale, contradictory, or duplicate memories
- **Memory consolidation**: Merge daily notes into long-term memory
- **Context pruning**: Archive outdated context

### 🔒 Security & Maintenance
- **Security audit**: Daily security checks and fixes
- **Config drift detector**: Catch unexpected configuration changes
- **Secret scanner**: Find accidentally committed secrets

### 📅 Calendar & Awareness
- **Daily agenda**: Morning summary of events and deadlines
- **Deadline reminder**: Alerts on approaching deadlines
- **Time-zone aware standups**: Daily standup adjusted for your current timezone

## Why This Matters

**AI agents should compound in value over time.**

Every interaction should make them slightly better. Every project should teach them something. Every mistake should be an opportunity to improve.

Better Claw implements that philosophy through scheduled feedback loops.

Instead of a static tool that does what it's told, you get a system that:
- Learns your preferences
- Monitors what matters
- Surfaces insights proactively
- Evolves based on experience

## Getting Started

Better Claw is open source and easy to set up:

```bash
# Clone the repository
git clone https://github.com/ripxg/better-claw.git
cd better-claw

# Import recommended starter jobs (all disabled by default)
./scripts/import-recommended.sh

# Review and enable jobs
openclaw cron list --include-disabled
openclaw cron update --job-id <id> --patch '{"enabled": true}'
```

All jobs are disabled by default. Start with 2-3 jobs and see how they fit your workflow.

The [live catalog](https://better-claw.vercel.app/) lets you browse all available jobs with descriptions, schedules, and requirements.

## Best Practices

1. **Start small** — Enable 2-3 jobs and see how they fit
2. **Adjust delivery** — Use Telegram/Discord for async updates
3. **Respect quiet hours** — Schedule intensive jobs during working hours
4. **Iterate prompts** — Customize templates to match your preferences
5. **Monitor noise** — If a job isn't providing value, disable it
